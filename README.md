# 日本麻將 番數與點數計算

點選牌面組成手牌，自動判定役種、符數與實際收支的網頁工具。不需安裝、不需連網，用瀏覽器打開 `index.html` 即可使用。

## 檔案結構

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 頁面結構 |
| `styles.css` | 外觀樣式。預設兩欄（左邊操作、右邊牌面與計算），平板橫擺整頁一個畫面放得完不必捲動，九百像素以下改成上下單欄 |
| `scoring-engine.js` | 計算核心：手牌拆解、役種判定、符數與點數計算。不依賴任何瀏覽器 API，可單獨在 Node 執行 |
| `interface.js` | 點牌、副露、寶牌等操作，以及結果呈現 |
| `tests/scoring-tests.js` | 三十項回歸測試 |

執行測試：

```
node tests/scoring-tests.js
```

## 畫面尺寸

- 平板橫擺是主要使用情境，一千四百像素以下會縮小牌面與間距，讓整頁在一個畫面內放得完，不需要捲動。螢幕高度低於六百四十像素時再縮一級。
- 九百像素以下改成上下單欄，順序是基本設定、和牌狀況、點牌、寶牌、和牌張、手牌、副露、確定計算。手機直式可以上下捲，但不會出現左右捲軸。
- 連點兩下不會放大畫面，雙指縮放仍然可用。

## 操作方式

1. 設定場風、自風、連莊數（零到十本場）與和牌方式（自摸或榮和兩顆按鈕；自風選東就是莊家）。
2. 勾選和牌狀況。不符合條件的選項會自動停用，例如副露後不能立直、自摸時不能搶槓。
3. 點右邊的寶牌、和牌張、手牌、副露四個框決定牌要加到哪裡，再點左邊牌庫的牌。副露框右側還能選吃、碰、明槓、暗槓。
   點牌標題旁也有一排一樣作用的快捷鈕（寶牌、和牌張、手牌，以及一個副露下拉選單），手機上不必捲到下面就能換目標。
4. 和牌的那一張單獨放在「和牌張」框，只能放一張；手牌框放其餘十三張（有副露就再扣三張）。各框的牌都是點右上角的 × 移除。
5. 十四張湊齊後按下「確定計算」，結果以彈出視窗顯示：級別、番數、符數、點數、役種明細、符數明細與牌型拆解。還沒湊滿時按鈕會停用並顯示還差幾張。

吃的操作是點順子裡最小的那張，例如點三筒代表吃成三四五筒。副露裡若有五，卡片上會出現「赤五」切換鈕。

採用的規則細節放在標題旁的「?」圈鈕，點了會彈出說明視窗，按 Esc 或點視窗外側關閉。

## 採用的規則

規則基準為雀魂／天鳳標準，兩者有差異時以雀魂為準：

- 食斷有：吃碰後仍可和斷么九。
- 赤寶牌每種花色各一張，每張一番。寶牌本身不算役，沒有役就不能和牌。
- 寶牌欄填的是寶牌本身，不是牌山翻開的指示牌，不需要自己換算下一張是什麼。
- 表寶牌與裏寶牌填在同一份清單，翻開幾張就填幾張，每一筆各算一次，不會自動加倍。同一種牌被兩張指示牌指到時填兩次，那種牌在手牌裡每張就算兩番。上限十張：嶺上牌只有四張，一局最多槓四次，所以表寶牌指示牌最多是原本那張加四張槓寶牌共五張，裏寶牌同樣五張。
- 同一種牌最多填四次。要讓某張牌變寶牌，指到它的那種指示牌總共只有四張，表層裏層都是從這四張裡出的。
- 裏寶牌只有門前立直和牌才會翻開。沒有立直時不要填，程式不會自動補，也不會把同一張重複計算。
- 十三番以上為累計役滿。沒有切上滿貫，四番三十符是 7700 點而不是滿貫。
- 役滿一律一倍，不同役滿同時成立時倍數相加（不採用雙倍役滿）。四暗刻單騎、國士無雙十三面、純正九蓮寶燈會標示出來，但倍數仍是一倍。
- 連風牌（場風與自風相同）當雀頭算四符。這是雀魂的算法，天鳳與競技團體多半算兩符。
- 七對子固定二十五符，平和自摸固定二十符，副露平和型榮和固定三十符。
- 榮和時完成最後一組面子的那張牌算明刻，不計入暗刻；四暗刻必須全部自己湊齊，單騎榮和除外。
- 連莊累積的本場，每一本場三百點：榮和由放銃者一人多付，自摸由三家各多付一百點。結果區會把和牌點與本場加點分開列出。
- 按下確定計算後若判定不能和牌，除了說明原因，還會一併算出詐和的滿貫罰符：莊家賠三家各四千（合計一萬二），子家賠莊家四千、另外兩家各兩千（合計八千）。這是手牌已經倒下的情形；牌還沒倒就發現的話，一般只判和牌放棄。手牌張數不足之類的輸入不完整不會顯示罰符。
- 同一副手牌有多種拆法時，取點數最高的一種；點數相同時取番數高者。

未涵蓋的項目：立直棒（供託）、流局滿貫、人和、三家和、包牌責任制，以及各種地方役。場上每支立直棒一千點要自己另外加。
