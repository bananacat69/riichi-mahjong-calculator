# 日本麻將 番數與點數計算

點選牌面組成手牌，自動判定役種、符數與實際收支的網頁工具。不需安裝、不需連網，用瀏覽器打開 `index.html` 即可使用。

打開後是位置模式（風位桌面）。畫面左緣由上到下有四個標籤：齒輪打開設定起始值側邊欄（寬三百像素），計算機打開計算側邊欄，問號打開採用的規則細節側邊欄（寬四百八十像素），扳手打開調整點數側邊欄（寬三百二十像素）；同時只開一個，打開時其他標籤先隱藏。計算側邊欄寬螢幕佔畫面九成，右側留一條看得到桌面，手機（五百六十像素以下）蓋滿整個畫面。再按一次標籤、點側邊欄外的半透明遮罩或按 Esc 收合。手機直放（寬五百六十像素以下且直向）時，四個標籤改在畫面上緣水平置中排成一列，側邊欄從上方滑下、寬度蓋滿，高度依內容、最多留出標籤的高度，打開的那個標籤移到側邊欄下緣。每次打開計算側邊欄時，桌面的場風與連莊數會帶入計算的場風、連莊數選單（連莊數超過十以十計）。

## 檔案結構

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 頁面結構 |
| `styles.css` | 外觀樣式。計算側邊欄預設兩欄（左邊操作、右邊牌面與計算），平板橫擺整頁一個畫面放得完不必捲動，九百像素以下改成上下單欄 |
| `scoring-engine.js` | 計算核心：手牌拆解、役種判定、符數與點數計算。不依賴任何瀏覽器 API，可單獨在 Node 執行 |
| `interface.js` | 點牌、副露、寶牌等操作，以及結果呈現 |
| `tests/scoring-tests.js` | 三十項回歸測試 |
| `fonts/yuji-boku-east-south-west-north.woff2` | 位置模式的書法字型 Yuji Boku，只收東南西北四個字（SIL Open Font License 1.1） |

部署前把 `index.html` 裡 `styles.css`、`scoring-engine.js`、`interface.js` 網址後面的 `?v=` 版本號改成新的，手機瀏覽器才會抓新檔，不會沿用暫存的舊檔（GitHub Pages 允許暫存十分鐘）。

執行測試：

```
node tests/scoring-tests.js
```

## 畫面尺寸

- 平板橫擺是主要使用情境，一千四百像素以下會縮小牌面與間距，讓整頁在一個畫面內放得完，不需要捲動。螢幕高度低於六百四十像素時再縮一級。
- 九百像素以下改成上下單欄，順序是基本設定、和牌狀況、點牌、寶牌、和牌張、手牌、副露、確定計算。手機直式可以上下捲，但不會出現左右捲軸。
- 連點兩下不會放大畫面，雙指縮放仍然可用。

## 操作方式

1. 設定場風、和牌者、連莊數（零到十本場）與和牌方式（自摸或榮和兩顆按鈕）。和牌者選的是和牌那家的自風，一開始不預設，選東就是莊家；還沒選時天和、地和這類限定莊家或子家的和牌狀況先停用。選榮和時旁邊出現放銃者選單，選項是和牌者以外的三家。沒選和牌者、榮和沒選放銃者都不能計算。
   和牌者與放銃者選單的選項寫成「東（人名）」：打開計算側邊欄時，依桌面目前的莊家位置換算東南西北各坐哪個座位，帶入設定起始值側邊欄填的名稱；沒填名稱只顯示風字。
2. 勾選和牌狀況。不符合條件的選項會自動停用，例如副露後不能立直、自摸時不能搶槓。
3. 點右邊的寶牌、和牌張、手牌、副露四個框決定牌要加到哪裡，再點左邊牌庫的牌。副露框右側還能選吃、碰、明槓、暗槓。
   點牌標題旁也有一排一樣作用的快捷鈕（寶牌、和牌張、手牌，以及一個副露下拉選單），手機上不必捲到下面就能換目標。
4. 和牌的那一張單獨放在「和牌張」框，只能放一張；手牌框放其餘十三張（有副露就再扣三張）。各框的牌都是點右上角的 × 移除。
5. 十四張湊齊後按下「確定計算」，結果以彈出視窗顯示：級別、番數、符數、點數、點數移動（用人名列出和牌者加多少、每個付錢的人扣多少，沒填名稱寫「東家」這類稱呼）、役種明細與符數明細。最下面的「確認」把點數移動換算回座位，加到位置模式的四家點數上，並關掉結果視窗與計算側邊欄回到桌面：有增減的那幾家先在點數下方用紅字顯示增減量兩秒，兩秒後才把數字加減到點數上（新點數按下確認時就已存起來，兩秒內重整也不會漏加）；不按確認直接關閉則點數不變。不能和牌時沒有確認鈕。還沒湊滿時按鈕會停用並顯示還差幾張。

吃的操作是點順子裡最小的那張，例如點三筒代表吃成三四五筒。副露裡若有五，卡片上會出現「赤五」切換鈕。

標題右邊的「清空」只清掉放進寶牌、和牌張、手牌、副露的牌；場風、和牌者、放銃者、連莊數、和牌方式與和牌狀況的勾選都保留。

## 位置模式

位置模式不顯示標題，正方形框撐滿整個視窗且不產生捲軸。正方形四邊各有一個長方形，放四家的自風，字都朝向坐在那一邊的人；長方形從邊的中段往坐在那一邊的人的右手方向延伸到正方形的邊，四個長方形首尾相接圍成一圈，自風字仍在原本中段的位置；自風是東（莊家）的那一格框線是紅色。正中央的紅字是場風，右上角的紅點數量是第幾局，整塊中央區朝向莊家。按右下角的逆時針箭頭換莊，四個自風字與中央區一起逆時針轉一格，局數加一；東四局之後進南場，北四局之後回到東一局。長按箭頭半秒倒退一局，順時針轉回一格，按錯時用。莊家的東右下角有皇冠圖示的連莊鈕，點一下右上角的連莊數加一、長按減一，零時不顯示；換莊後歸零，倒退時還原成換莊前的數字。中央區左下角的骰子鈕擲兩顆骰子，翻滾後顯示加總，並讓開門座位（從莊家逆時針數，莊家算一）的長方形閃兩下；點骰子結果或停留三秒後收起，加總會留在骰子鈕上，換局或重置時清掉。每家長方形延伸出來那一格顯示該座位的點數（上下置中、稍微靠左），朝向坐在那一邊的人，預設 25000；點數只顯示、不能在桌面上直接修改，會改變點數的只有計算結果的確認、設定起始值側邊欄的確認、調整點數側邊欄的確認與右上的重置；負數顯示紅色。點數跟著座位（人），換莊時不動。局數、連莊數與點數重整後會保留，右上角的「重置」回到東一局、沒有連莊，四家點數回到起始點數。設定起始值側邊欄裡是起始點數，預設 25000，按減號、加號一次調 1000、最低 0；按「確認」跳出確認視窗，按「確定」才把四家點數都改成起始點數並收合側邊欄回到桌面，按「取消」或 Esc 回到側邊欄、不改。起始點數下方是四家名稱，依東一局開局時的自風分成起始東（下方）、起始南（右邊）、起始西（上方）、起始北（左邊），最多八個字；邊打邊顯示在桌面該座位的點數上方，前後空白不算，清空就不顯示。名稱跟著座位（人），換莊時不動，重整後保留，重置不會清掉。

調整點數側邊欄直接修正桌面的點數：四家各一張卡片，依起始東、南、西、北的座位排列，只顯示名稱（沒填就空白）與點數，下面是 −1000、−100、+100、+1000 四顆鈕；改過的那家在目前點數前面接上算式，例如「4200+500=」後面接著目前點數 4700。標題旁顯示調整後四家總分與開局總分（目前起始點數乘四）的差距，多了寫「+多少」、少了寫「−多少」並轉成紅色，剛好相等寫「±0」。每次打開都從桌面目前的點數開始，沒按確認就收合的調整會丟掉。沒有任何變動時確認鈕停用；按確認跳出確認視窗，逐行列出誰從多少改成多少，按「確定」才寫回桌面並收合側邊欄，按「取消」或 Esc 回到側邊欄。起始點數重整後會保留。

## 採用的規則

規則基準為雀魂／天鳳標準，兩者有差異時以雀魂為準：

- 食斷有：吃碰後仍可和斷么九。
- 赤寶牌每種花色各一張，每張一番。寶牌本身不算役，沒有役就不能和牌。
- 寶牌欄填的是寶牌本身，不是牌山翻開的指示牌，不需要自己換算下一張是什麼。
- 表寶牌與裏寶牌填在同一份清單，翻開幾張就填幾張，每一筆各算一次，不會自動加倍。同一種牌被兩張指示牌指到時填兩次，那種牌在手牌裡每張就算兩番。上限十張：嶺上牌只有四張，一局最多槓四次，所以表寶牌指示牌最多是原本那張加四張槓寶牌共五張，裏寶牌同樣五張。
- 同一種牌最多填四次。要讓某張牌變寶牌，指到它的那種指示牌總共只有四張，表層裏層都是從這四張裡出的。
- 裏寶牌只有門前立直和牌才會翻開。沒有立直時不要填，程式不會自動補，也不會把同一張重複計算。
- 十三番以上為累計役滿。沒有切上滿貫，四番三十符是 7700 點而不是滿貫。
- 役滿一律一倍，不同役滿同時成立時倍數相加（不採用雙倍役滿）。四暗刻單騎、國士無雙十三面、純正九蓮寶燈會標示出來，但倍數仍是一倍。
- 連風牌（場風與自風相同）當雀頭算四符。這是雀魂的算法，天鳳與競技團體多半算兩符。
- 七對子固定二十五符，平和自摸固定二十符，副露平和型榮和固定三十符。
- 榮和時完成最後一組面子的那張牌算明刻，不計入暗刻；四暗刻必須全部自己湊齊，單騎榮和除外。
- 連莊累積的本場，每一本場三百點：榮和由放銃者一人多付，自摸由三家各多付一百點。結果區會把和牌點與本場加點分開列出。
- 按下確定計算後若判定不能和牌，除了說明原因，還會一併算出詐和的滿貫罰符：莊家賠三家各四千（合計一萬二），子家賠莊家四千、另外兩家各兩千（合計八千）。這是手牌已經倒下的情形；牌還沒倒就發現的話，一般只判和牌放棄。手牌張數不足之類的輸入不完整不會顯示罰符。
- 同一副手牌有多種拆法時，取點數最高的一種；點數相同時取番數高者。

未涵蓋的項目：立直棒（供託）、流局滿貫、人和、三家和、包牌責任制，以及各種地方役。場上每支立直棒一千點要自己另外加。
